## 会浪费你时间的坑（全部实测过）

| 坑 | 事实 |
|---|---|
| **`grep` 不可靠** | 这环境是 ugrep，两次对确实存在的字符串返回空。**用 python 搜。** |
| **`str.replace` 静默失败** | 锚点不匹配就原样返回、不报错。栽四次，其中一次把文件从 1021 行变成 **119 万行**。**用 Edit 工具，或 python 的 `str.index`。** |
| **SQL 注释里不能有反引号** | schema 是一个模板字符串，一个反引号提前结束它。 |
| **`.test.ts` 过类型检查** | 新树和老树相反，`tsconfig.src.json` 包含它们。 |
| **浏览器面板视口可能 0×0** | 那时所有 `getBoundingClientRect` 都是垃圾，`fit()` 会算出 1 列并真发给 pty。先 `resize_window` 再量。 |
| **preview_start 起不来面板** | spawn 的 cwd 是 `/` 且不可读。用 Bash 后台起，再 `preview_start {url}`。 |
| **Codex 目录信任不继承** | 不从父目录继承，也不能用 `-c` 设。 |
| **`launchInto` 对活会话丢 argv** | 第二段提示词送不进去。用 `PanelSessions.type`，而且**文字和回车必须分两次写**——一次写会被当成粘贴，回车被吃掉。 |
| **Bash 里 curl 连不上 localhost** | 沙箱挡的。用浏览器工具验。 |
| **每个动作按钮在 `live` 时都禁用** | 所以「结束这个终端」是承重的出口，不是便利功能。 |
