## 〇、一次性设置（做一遍就行）

**1. 注册 MCP**

```bash
cat >> ~/.codex/config.toml <<'TOML'

[mcp_servers.stagepass]
command = "/Users/zhanghr/Desktop/stagepass/node_modules/.bin/tsx"
args = ["/Users/zhanghr/Desktop/stagepass/src/mcp/server.ts"]
TOML
```

Claude Code 那边同理（`claude mcp add`，命令和参数一样）。

**2. 起工作台** —— 在**你要做的那个项目目录里**跑：

```bash
cd ~/Desktop/你的项目
npm --prefix ~/Desktop/stagepass start -- $(pwd)
```

它绑在你起它的那个仓库上，**没有项目选择器**。换项目就换目录重起一次。

**3. 浏览器开** `http://127.0.0.1:4399/`，点进 PRD 阶段。

## 一、每天怎么用

### ① 聊

在 Codex / Claude Code 里跟模型随便聊你想做什么。**StagePass 完全不参与**。

开头跟它说一句：

> 需要我做决定的时候调 `stagepass_ask`，别用文字问我。
> 要动手写产物之前先调 `stagepass_brief`。

### ② 它问你（一次一条）

聊到它觉得该确认了，它调 `stagepass_ask` —— **一张带选项的表单弹到你面前**，你选。

- 第一次调会先弹一个 MCP 许可框，按掉（每条会话一次）
- 你关掉不答也行，它会收到「没答上」继续走
- 每一问一答都进账本，面板右栏「问过我什么」看得见

### ③ 它写 PRD

它调 `stagepass_brief` 拿到：七节各要答什么、还缺哪几节、这一阶段的标准、
**产物写到哪个文件**（`docs/PRD-<CHG>.md`，路径由 StagePass 给，它不用编）。

然后它直接写那个文件。**没有「提交」这一步** —— 文件就是接口。

### ④ 你逐节提意见

面板上「产物（逐节留意见）」那一栏：七节正文摆着，每节下面一个输入框。
**打一句，回车。**

正文你不用改（也不该改）—— 正文归模型，你只判。

### ⑤ 它改，并逐条交代

它再调 `stagepass_brief`，这次带回你的意见（编了号）。改完调
`stagepass_respond` 逐条交代。

**明说不改也算交代**（"不改：那是 Arch 的事"）—— 闸门要的是有下文，不是必须听话。

④⑤ 循环，直到你不想再提。

### ⑥ 放反方（可选，不挡门）

另开一条会话，说一句：

> 你是这一轮的反方，调 `stagepass_brief` 传 `role="blue"` 拿题面。

它拿到的**只有正文和标准，没有你的意见** —— 互盲盲的就是这一层：
看了意见它就只会顺着你俩的思路说。

### ⑦ 点头

面板那一栏顶上写着还差什么：

```
还差：2 节没写 · 1 条意见没下文 · docs/PRD-CHG-004.md
形式齐了（docs/PRD-CHG-004.md）· 就等你点头        ← 第一道闸绿了
```

第一道闸是**代码判的**（七节非空 + 每条意见有下文），第二道是你。

## 二、模型会调的三个工具

| 工具 | 什么时候 | 它拿到什么 |
|---|---|---|
| `stagepass_ask` | 需要你做决定 | 你选的那一项 |
| `stagepass_brief` | 动手写产物之前 | 阶段 / 七节 / 缺哪节 / 标准 / 正文 / 你的意见 |
| `stagepass_respond` | 改完之后 | 逐条交代（按序号，不抄 id） |

**模型永远只生成两种东西：枚举里的选择，和散文。** 没有 id、没有路径、没有阶段名——
那些全由 StagePass 这边填，于是「抄错一个 UUID 整份作废」在这条路上不存在。

---

## 三、你在面板上只做三件事

1. 看七节正文（只读）
2. 逐节留意见（打字 + 回车）
3. 看每条意见的下文，和顶上那行「还差什么」

阶段环不动。

---

## 四、还**没有**的东西，说清楚

- **⑦ 的「进 Spec」按钮还没接。** 第一道闸的状态摆出来了，但真正的阶段流转还得
  手工（或者走老的裁决那条路）。接它要先解决「判据单怎么进 Evidence」那一批。
- **Spec 之后的阶段没重做。** 这一版只做了 PRD 的回路。
- **模型会不会真的用工具、还是继续打字问你 —— 强制不了。** Codex 的 hook 只看得见
  tool call，看不见「它决定打字」。只能靠你开头那句话和 `AGENTS.md`。
- **一个项目一个工作台。** 端口只有一个，换项目要重起。
