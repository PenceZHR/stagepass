## 一、三个层级各自能证明什么

| 层级 | 怎么跑 | **能**证明 | **不能**证明 |
|---|---|---|---|
| 纯域 | `node --import tsx --test src/domain/*.test.ts` | 规则算对了 | 有没有人去调它 |
| 存储 | 同上，`new Database(":memory:")` | 存得进读得出 | 文件真的落在磁盘上了 |
| 接线 | `src/web/*.test.ts` | 路由分岔对 | 界面点下去有反应 |
| **真机** | 手，一条真 Codex 会话 | 人点下去有反应 | —— |

**判据：前三层全绿 ≠ 这条链是通的。** §四那次事故里，三层全绿，链断在层与层之间。

## 二、逐任务的测试清单

### T1 `domain/ask.ts`

- 序号越界 → `reason` 里**有具体范围数字**（不是「越界了」）
- `sheetCount = 0` 时允许 `ordinal = null`
- 选项 <2 或 >6 → `bad_options`
- `question` 空白串 → 拒
- **反面**：校验失败时**不抛异常**。抛了模型只知道「失败了」，改不过来。

### T2 `store/ask-store.ts`

- **往返**：写 N 条 → 换一个全新空库 → `rebuildFrom` → `list()` 深相等
  （这是「文件为准」的**唯一**证明，缺了它这条设计就是句口号）
- 回答是**追加一条补记**，原行一个字节都不变
- 文件写失败时**库也不写**（否则库里有、文件里没有，而重建以文件为准）
- **新陷阱**：`jsonlPath` 必须指到 tmpdir。这是这棵树上第一个往**项目目录**写文件的
  store —— 测试写错路径会在真仓库里落 `.stagepass/asks.jsonl`。
  每个测试用 `mkdtempSync(join(tmpdir(), "ask-"))`。

### T3 `web/ask-route.ts`

- 零条 waiting → `no_open_round`，`reason` 说得出该先做什么
- 多于一条 waiting → `ambiguous_round`（**不许猜一条**）
- **版本钉死**：备完之后把库里 rubric 换掉，`rubricId` 仍是备那一刻那份
- ordinal → rubricId 映射逐条正确

### T4 `mcp/server.ts`

- 工具表**有且只有** `stagepass_ask`（多一个少一个都红）
- **薄客户端护栏**：这个文件的依赖闭包里，`src/` 下的模块只允许 `import type`。
  一旦它 import 了业务，「三个进程锁三份代码」就回来了。
- 工作台没起来 → 回 `workbench_not_running` + 起它的命令，**且没有新进程被 spawn**
- **收尸**：起真 server 的测试必须在 `after` 里 kill，否则残留进程锁着端口，
  下一次跑测试红在一个完全无关的地方

### T5 面板

- `renderAsks` 是纯函数，**真解析输出**，不是对源码正则（见 §四·1）
- 改完 `panel.js` 必须过：抄成 `.mjs` → `node --check`
- 轮询在 `document.hidden` 时停

### T6 `domain/rubric-sheet.ts`

- 答一半不作废：`missing` 报得出是哪几个序号
- `claim=pass` 但证据为空 → 算 `missing`，**不算 `problems`**
  （它不是格式错，是没交代 —— 闸门要拦的正是这个）
- 序号重复、序号越界 → 进 `problems`，每条带序号
- **和 `worklist` 同构**：同一份文本喂给两个 reader，行格式解析结果一致

### T7 `domain/gate.ts`

- 判据单缺一条 → `approve` 不在 `permitted`，且 `refusals.approve` **说得出第几条**
- `reject` / `retry` / `sendBack` **不受**判据单影响
  （出口被证据不好挡住，Change 会卡到没有合法动作）
- `sheetMissing` 进 `snapshot`：补完一条，旧的裁决围栏必须失效
- **回归**：`unresolved()` 的既有行为一个字不变（P2 仍然不挡 —— 这一期不治它）

### T8 护栏

- 题面里出现的每个 `stagepass_*`，都在工具表里
- **这条测试必须先红一次**（现在题面里还留着 `stagepass_next`）。
  没红过的护栏不算护栏。

## 三、真机验收（测试代替不了的）

一条真 Codex 会话，逐条点出来，结果记进 `docs/EVIDENCE-*.md`：

1. 模型调 `stagepass_ask` → **表单真的弹** → 人点 → 答案回到模型。**零手抄。**
2. 同一条出现在浏览器面板上，字段完整。
3. 模型给一个越界序号 → **表单不弹**，模型收到带范围的错误、并自己改对重试。
4. 判据单缺一条 → 面板上「进入下一阶段」是灰的，**且说得出缺第几条**。
5. 杀掉工作台 → 重开 → 留档还在；删掉库 → `rebuildFrom` → 一条不少。
6. 关掉表单不答 → 模型收到 `pending`，**继续往下走而不是卡住**。

**为什么必须是手**：elicitation 要一个真人点。任何「模拟人点」的测试证明的是
mock 的行为，不是这条链。

## 四、会撒谎的绿 —— 这一节最贵

### 1. 前端测试全是正则（2026-08-17 实测，新树，仍然成立）

`src/web/*.test.ts` 里针对浏览器模块的断言全是 `readFileSync` + `assert.match`。
`assert.match(src, /new THREE.WebGLRenderer/)` 只证明这行**字符串在文件里**。

代价：整张 3D 星图**从来没显示过**（canvas 被撑成容器的 devicePixelRatio 倍，
只看得见左上角四分之一），而 1137 条全绿、控制台 0 error、交接文档写着
「浏览器验收通过」。

**T5 的要求**：`renderAsks` 抽成纯函数，测**它的返回值**。
不许再加一条 `assert.match(panelJs, /renderAsks/)`。

附带一条：正则会**反向钉死设计**（曾有一条 `assert.doesNotMatch` 把设计里明确要求的
时间轴钉成了禁止项）。新增断言前问一句：它钉的是行为还是我的写法。

### 2. 删掉的东西，题面还在叫（2026-08-19 实测，就是这一期要防的）

`stagepass_next` / `stagepass_answer` 随 `src/plugin/` 删掉，题面还在叫裁判去调，
**1177 条全绿**。后果：每轮 gap 表态全丢、每条标准记 `not_assessed`，
而标了阻断的 `not_assessed` 是把闸门**沉默地**关死。

**这就是 T8 存在的理由。** 这一期要加两个新工具名，同一个坑就在脚下。

### 3. 不要看 `$?`，要看计数行

老树实测过 `pnpm test` 全量 **exit 0 但有测试失败**。新树没复验过 ——
便宜的防法是每次都读 `ℹ fail` / `ℹ cancelled` 两行。

**`cancelled` 必须看**：套件级 `timeout` 超时会取消尾部测试，而汇总仍报 `fail 0`。

**别把全量输出管道给 `tail`** —— 汇总计数行会被失败详情挤掉，只剩堆栈。

### 4. `grep` 会静默跳过含 NUL 字节的文件

报 0 个匹配，和「确实没有」长得一模一样。判据：`file <path>` 说 `data` 而不是 `text`。
用 `grep -a` 或直接读。

### 5. **已经不成立的两条 —— 别再照着老树做**

- **`tsc --noEmit` 不覆盖测试文件** → 老树的事。**新树覆盖**（2026-07-29 反转）。
  别再写 `.typecheck.ts` 那套变通。
- **多测试文件共库的 SQLite 争用** → 老树的事。新树 `--test-concurrency=1` +
  每个 store 测试自己 `new Database(":memory:")`，不成立。
  也没有 `db-write-policy.json` 要登记。

## 五、不写的测试

写了会变成噪音，或者会把实现形状钉死：

- **不对 `panel.js` 加新的正则断言**（见 §四·1）

## 七、这份 TestPlan 自己的漏洞（照直说）

1. **`pending` 那条路只有真机能验。** 模型收到 `pending` 之后到底会不会卡住，
   取决于模型，不取决于我们的代码。真机验收 6 是唯一的证据，而且**它可能每个模型
   不一样**。
2. **「模型会不会用工具、还是继续打字问」测不了。** `PreToolUse` 看不见「决定打字」。
   这是软约束，只能靠题面和 AGENTS.md。**别写一条假装能测它的测试。**
3. **判据单里散文引用的路径存不存在**，T7 判了；但「这段散文是不是真的支持这条判据」
   判不了，也不该判 —— 那是人的活，摆到面板上让人看。
