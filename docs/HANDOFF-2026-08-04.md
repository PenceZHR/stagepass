## 一、这一趟最重要的一件事：一整套设计被 Codex 的行为变更推翻了

`0.146.0-alpha.3.1` 上做的，今天是 `0.146.0` 正式版。**地基动过。**

### 1.2 于是 `3d32ea3`（producer rubric 直连蓝方）结构上不可能工作

那个提交为了这条路把围栏协议整个删了（净减 670 行）。**唯一还通的通道是父线程，
也就是裁判。**

### 1.3 换成了什么：两个文件路径由裁判原样转达（`d5ed0ec`）

```
StagePass 写   rubric-CHG-1-PRD-r3.md          按 1..N 编号，零 criterion key
               rubric-answers-CHG-1-PRD-r3.md  空壳
裁判转达       只转这两个路径，不转标准正文
反方写回       1: yes —— 依据…
StagePass 读   按序号映射回 criterion key
```

**数不对就整份作废**（用户拍板）—— 序号取值空间只有 `1..N`，缺号/重号/越界都可检测，
这正是它和 40 字符 UUID 的本质区别。

真机端到端验过（PRD 第 3 轮）：四条判定**逐条落在正确的标准上**，依据措辞与各自的
标准语义吻合（第 3 条判 yes 引的是「Out of scope 明确排除了…」，正对着「明确写出
这一次不做什么」）。错一位就会是一眼可见的荒谬，没有发生。

### 1.4 顺带一条：子 Agent 继承父线程的全部历史

`forked_from_id` = 父线程。第 5 轮的反方 rollout 里有 **15 条继承来的
`user_message`**，第 1 到第 5 轮的裁判提示词全在。

**所以「每轮一个新反方，从零开始怀疑」只在跨阶段时成立。** 同阶段内它记得前面每一轮
——而这也正是「同一个问题用同一个 id」能work的原因（它记得用过什么 id）。

**一个实验因此做不成**：想单独考验「人驳回的 gap 不许被重开」那道护栏，抑制掉当前轮
提示词里的 settled 清单没用，它从上一轮的继承历史里照样读得到。那道护栏的真机触发
条件**在当前架构下造不出来**，只能靠离线证明（自检过会红）。

### C. 一个查了一小时没查出根因的故障

环境变量（用 `zsh -l` 起了一个对照，一次成功）、插件配置、绑定的线程。argv 从用户

pty 13 / 系统 28 用于 511，进程只跑了 16 分钟）。

**重启面板就好了，而且那个实例从第一次起就没成功过。** 证据只指向「那个进程实例
坏了」，而那个状态是什么没抓到。

**下次要能抓到，得改一件事**：一个会话如果在 1 秒内就死了，把它吐出来的头几百字节

## 五、动手之前必须知道的

### 1. 每个会话第一次调 stagepass 工具要人放行

`-a on-request` 之下，Codex 会先弹自己的许可提示（`Allow the stagepass MCP server
to run tool "stagepass_ask"?`）。**那道门 StagePass 看不见，也不计入问人的 15 分钟。**
2026-08-03 一次录需求就这么废掉：人的预算被那道门吃掉一截，表单还没露面就到点，
`sessions.close()` 一执行终端当场消失。

`--ask-timeout` 把旋钮交出来了，但病根没治。

### 2. 「一路回车」会让需求变成空的

录需求那张表第一趟全是选项，一路回车＝每格取第一项。验机制够用，但那样录出来的
需求**没有内容**。2026-08-03 的 `CHG-1` 就是这么废的：说了「修一个能复现的错误」
却没说是哪个，于是两条 P0 五轮一动没动，红方编不出来。

对比 `CHG-001`（用户认真答的）：两轮就关掉六条。**差别不在机器，在输入。**

### 3. `ps` 会把非 ASCII 转义

查 argv 要从 rollout 或面板日志读原文。这一趟又踩了一次（`M-;M-eM-.M^C…`）。

### 4. 老坑照旧有效

- Bash 的 `curl` **这一趟能连上 localhost 了**（和之前记的相反，但别依赖它）
- `preview_start({name})` 起不来 → 后台 Bash 起进程 + `preview_start({url})`；
  **一个会话只开一次 tab，之后一律 navigate**
- 改完代码要重启面板，**别在有轮在跑的时候重启**
- 面板前端 `read_page` 返回空树，只能用 `javascript_tool`；坐标比例每次实测标定
  （这一趟量到 1.6006）
