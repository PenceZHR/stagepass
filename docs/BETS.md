# 赌注单

> **会改的文件。**改的时候不要删旧的——`~~划掉~~` 保留。
> 「我原来这么赌」本身就是不可重导的信息。
>
> 什么时候改：一条赌注被证伪时。改完在 `LOG.md` 追一行。

格式：一条一行，按「最可能是假的」排在最前面。

```
[ ] 高危 · <这件事要成立，什么必须为真>
[x] 已验 · <验过了，真的>
[~] 已死 · <被打掉了，见 LOG.md 那条>
```
