> **它前置于现有八阶段环，不改环。**环管收敛期，这一层管探索期，

## 一、一句话

**一个可以算、可以查的 iteration 台账。不是流程引擎。**

MVP 阶段**没有闸门、没有判据单、没有阶段**。任何东西都不该拦你 ——
拦截属于收敛期，而收敛期的闸门也已经降成体检。

---

## 二、原子：iteration

一段反馈 = 一条。**在信息进来的地方切，不在活干完的地方切。**

```
id            it-NNNN        代码给，单调序号
opened        timestamp      代码给
feedback      text           人 —— 原样粘贴，不总结不润色
state         开着|待测|关了   人
result        成|部分|没成|没测  人 —— 仅 `关了` 时必填
```

四条硬规矩（见 `ITERATIONS.md`）：边界是可观察事件不是判断；id 单调不重用**不重排**；
粒度可以严重不均匀（它是地址不是度量单位）；已被引用的 id 冻结。

`it-0001` 是唯一没有前置反馈的一条 —— 初始押注，简要 PRD+spec+plan+build
全打包进去都行，因为它们会被 `it-0002` 的反馈一次性同时检验。

## 三、产出：封闭集合

**封闭是必须的** —— 地址指向的东西不确定，追溯就断了。

### 必产两样

| 产出 | 作者 | 为什么必产 |
|---|---|---|
| **原话** | 人 | 不可重导。半年后你要的是当时的措辞 —— 里面有犹豫、有没意识到的假设、有后来改了口的说法，总结会全抹掉。成本是复制粘贴 |
| **实测结果** | 人 | 不可重导。git 显示改了什么，不显示改完管不管用 |

> **「做了什么」不是必产。**那是可重导的 —— `git diff` 里全有。
> 写它等于给自己制造一份会过期的二手资料。
>
> **`没测` 是合法值，而且它是最重要的信号。**连续十条 `没测` =
> 你已经停止接触现实了，那正是 1177 条全绿的形状。未测率因此要算出来（§5）。

### 可选四样，各 0..N

| 产出 | 落在哪 | 备注 |
|---|---|---|
| commit 引用 | git | **代码不是产出，是引用。**sha 由 StagePass 按 message 里的 `it-NNNN` 从 git 抓 —— 不许手抄 |
| LOG 条目 | `LOG.md` | 大部分 iteration 产出 **0 条**，这是对的不是漏 |
| 边界改动 | `BOUNDARIES.md` | |
| 赌注变化 | `BETS.md` | 死掉时带 `killed_by` 指向打掉它的那条 LOG |

## 四、状态

```
开着  →  待测  →  关了
```

转换**全部归人**。`待测 → 关了` 时 `result` 必填 ——
这是全套唯一的必填校验，而且它是**代码判得了的**（格子空没空）。

---

## 五、StagePass 在这一层只做三件：算、提醒、取回

### 算 —— 它算得出而你懒得算的

| 数 | 怎么算 |
|---|---|
| **产出率** | 最近 10 条 iteration 产出的新 LOG 条数 |
| **未测率** | `result=没测` 占最近 N 条的比例 |
| **边界稳定度** | 每条 boundary 的改动次数 |

### 提醒 —— 两个，都是通知不是拦截

- **产出率枯竭**（最近 10 条只产出 0~1 条新 LOG，且无 `×N` 上升）→ 可以转段了
- **某条 LOG 从 `×1` 变 `×2`** → 同坑第二次

### 取回 —— 四步，全机械，没有一步靠回忆

```
grep 主题 LOG.md  →  it-NNNN  →  原话 + 前后几条  →  git log --grep it-NNNN
```

**这条路径断在哪里，哪里就是要修的地方。**它是这一层唯一的验收方式 ——
不是「记得全不全」，是「取不取得回」。

---

## 六、M2：唯一的耦合点

```
MVP 台账  ──M2──>  窄冻结  ──>  八阶段环
```

**M2 不能跳。**收敛期第一个动作是窄冻结，它的输入就是：

- `LOG.md` **按 `×N` 排序后的前十条**
- `BOUNDARIES.md` 里**改过三次以上**的那几条

跳过 M2 直接进环，第一个阶段就没有输入 —— 等于又一次在信息不足时定架构。

> **MVP 阶段的产出物不是代码，是那份排序过的清单。**
> 代码是要扔的，清单是要交的。交给环的不是一个仓库，是一份判据。

M2 本身不是 iteration，它是把所有 iteration 横过来。而因为 `×N` 是写的时候
顺手记的，M2 那天只需要**一次排序**，不需要整理 —— 工作量从「两天」降到「点一下」。

## 七、这一层自己的高危赌注

> **`×N` 频次在 200 条流水时的信号，会比 20 条时更清晰。**

如果规模上去反而糊了（同一件事被写成三种措辞、grep 撞不上、`×N` 永远停在 1），
整套的价值塌一半，**而且是静默地塌**。
